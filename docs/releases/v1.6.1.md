## Русский

### Исправлено

- **Vimeo:** если обычная ссылка вызывает ошибку входа веб-клиента, Napotom автоматически делает одну повторную попытку через встроенный плеер. Вручную менять ссылку не нужно; ключ доступа для видео по ссылке сохраняется.
- Исходная ссылка всегда проверяется первой. Другие ошибки не запускают обход, а отмена загрузки останавливает повторную попытку.
- Если повторная попытка не помогла, приложение показывает причину ошибки и подсказку про cookies Vimeo на выбранном языке интерфейса.
- Обновлены инструкции по Vimeo в README на русском и английском.

Для этого исправления обновите само приложение Napotom — обновления только yt-dlp недостаточно.

### Скачать

- **Windows:** скачайте `Napotom-Windows.zip`, распакуйте и запустите `Napotom.exe`.
- **macOS:** скачайте `Napotom-macOS.dmg`, откройте и перетащите Napotom в Applications.

### Проверка

66 автоматических тестов пройдены. На Windows проверены скачивание короткого фрагмента Vimeo в 720p без cookies и объединение видео со звуком.

## English

### Fixed

- **Vimeo:** when a regular link triggers the web client's login error, Napotom automatically retries once through the embedded player. There is no need to edit the URL; access hashes for unlisted videos are preserved.
- The original URL is always tried first. Other errors do not trigger the fallback, and cancelling a download stops the retry.
- If the retry fails, the app displays the error and a Vimeo cookies hint in the selected interface language.
- Updated the Vimeo instructions in both the Russian and English READMEs.

Update the Napotom application to get this fix — updating yt-dlp alone is not enough.

### Downloads

- **Windows:** download `Napotom-Windows.zip`, extract it, and run `Napotom.exe`.
- **macOS:** download `Napotom-macOS.dmg`, open it, and drag Napotom to Applications.

### Validation

All 66 automated tests passed. Downloading a short Vimeo clip in 720p without cookies and merging its video and audio were verified on Windows.
